Arc PAYG Estimator instructions

Start here

Use this discussion model to compare current SPLA licensing costs with Azure Arc PAYG for SQL Server and Windows Server. The currency selected on the Distributor tab applies to both estimator tabs.

Validate pricing, licensing rules, partner eligibility, incentive caps, and current program terms before using results in a reseller or customer offer.

How to use the estimator

  1. Open Distributor Tab, select a currency, enter the distributor's SPLA list prices plus the reseller SPLA and Azure PAYG prices, and configure DCO.
  2. Review distributor Azure PAYG pricing and its last refresh time on the Distributor tab.
  3. Open SQL Server PAYG or Windows Server PAYG Tabs, add workloads, select the edition and uptime profile, and enter total SQL cores or Windows VM counts and vCores.
  4. Configure reseller incentives for SPLA, MCI, and Growth Accelerator.
  5. Export to save a named project, or Import one to restore its prices, workloads, and incentive settings.
  6. Save offline Tool on the GitHub Pages site to download the complete estimator as a standalone HTML file.
  7. Review results for monthly and annual reseller costs, the three-year cost comparison, and total economic impact including incentives.

Calculation principles

  • SPLA inputs are monthly prices per two-core pack; the estimator converts the reseller SPLA price to a per-core monthly rate.
  • To avoid disclosing distributor SPLA list prices, reseller SPLA incentives are calculated using the reseller SPLA price. This overstates the incentive base by the distributor's SPLA markup.
  • Distributor Azure PAYG prices are per-core hourly rates from the Azure Retail Prices API and are embedded by the monthly GitHub Actions refresh.
  • The reseller comparison uses the entered SPLA and Azure reseller prices. The distributor business case compares reseller revenue with distributor SPLA list cost and embedded Azure cost after PEC.
  • PEC is fixed at 15% and deducted only from embedded distributor Azure cost.
  • DCO is configured once for both PAYG sections. A reseller DCO gain is shown only when pass-along is enabled and the share to pass along is greater than 0%; the distributor business case retains the remaining share.
  • For SQL Server, enter total SQL cores. The estimator enforces a minimum of four cores for each SQL workload row for both SPLA and PAYG.
  • Windows Server applies an eight-core minimum per VM for SPLA and a one-core minimum per VM for PAYG.
  • Uptime profiles convert to monthly hours; calculations retain full precision and round only for display.

Scope and limitations

  • The model supports SQL Server Standard and Enterprise core licensing, plus Windows Server Standard and Datacenter.
  • It does not model SQL Enterprise or Windows Datacenter unlimited virtualization on physical hosts, nor workloads shared by multiple end customers.
  • Azure prices outside USD can vary with exchange-rate updates. Check the displayed refresh time and verify current SPLA prices with the reseller.
  • Incentives depend on partner eligibility, onboarding, maximum earning opportunity, and current program terms.
  • This estimator is non-binding. Independently verify results before making an offer.
